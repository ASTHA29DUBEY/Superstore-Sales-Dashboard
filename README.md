**🛒 Superstore Sales Dashboard – Power BI Project**

**📊 Overview**
The Superstore Sales Dashboard is an interactive Power BI project that visualizes key sales insights, profits, and customer behavior. It helps businesses track performance, identify trends, and make data-driven decisions.

**🎯 Objective**
* To design a dynamic Power BI dashboard that provides:
* Overview of sales, profit, and quantity
* Insights by payment mode, segment, and region
* Month-wise sales and profit trends
* Performance by shipping mode, category, and sub-category

**📈 Dashboard Highlights**
* Total Quantity: 5239
* Total Sales: 341K+
* Total Profit: 27.4K+
* Avg Ship Days: 13
* Top Payment Mode: COD (41%)
* Top Segment: Consumer (48%)
* Top Category: Office Supplies (0.15M)
* Top Sub-Category: Chairs (46K)

**🛠️ Tools Used**
* Power BI Desktop – Visualization & dashboard design
* Excel Dataset – Data source
* Power Query – Cleaning & transformation
* DAX – Calculated metrics

**💡 Key Learnings**
* Built KPIs using DAX
* Created interactive visuals & filters
* Improved data storytelling with design and color themes

**🧠 Future Scope**
* Add sales forecasting
* Compare performance across all regions
